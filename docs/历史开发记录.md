# 自学 · 本地实用版

运行地址：http://127.0.0.1:4179 。这是实际应用，和 `src/prototypes/ai-learning` 的演示原型独立。

## 本地开发环境

先用这一入口调通真实流程，再考虑云端测试环境。双击 [启动开发环境.command](./启动开发环境.command)，保持窗口开启；或在项目根目录执行：

```sh
npm run dev --prefix apps/self-study
```

- 开发页面：[打开本地开发环境](http://127.0.0.1:51721)。
- 后端地址：`http://127.0.0.1:4180`；页面通过开发服务代理访问 `/api`。
- 修改前端即时更新；修改服务端文件自动重启后端。生成任务进行时不要改动服务端文件，重启后中断任务需重试。
- 按 `Control+C` 同时停止前后端。电脑重启后重新运行启动文件即可，数据保留。
- 默认独立保存到 `data-dev/`，包括 SQLite、原始上传文件和字幕。原有 `data/` 不迁移、不清空；旧实用版仍用原启动入口与 4179 端口。
- 需要改端口或数据目录时，将 `.env.development.example` 复制为 `.env.development.local` 后调整；不要把本地配置与数据提交到版本库。

检查与验证：

```sh
npm run doctor --prefix apps/self-study
npm run doctor:ai --prefix apps/self-study
npm run ai:smoke --prefix apps/self-study
npm test --prefix apps/self-study
```

`doctor` 检查通过前端代理访问的后端与项目接口；`doctor:ai` 额外检查已有官方 Codex 登录；`ai:smoke` 使用自编短材料做一次真实模型生成，会消耗少量账户额度，不写入学习项目。接口测试使用独立临时数据库，不更改开发或原学习数据。健康接口用于服务存活检查，不代表模型已连接。

环境依赖：Node.js 20.19 或更新版本、根项目与应用依赖，以及本机官方 Codex 登录。根项目依赖已由当前工作区提供；新机器需先在项目根目录安装依赖，再进入 `apps/self-study` 执行 `npm ci`。YouTube 字幕另外依赖下文的 Python 环境。

端口被占用时先关闭旧开发窗口，或修改本地配置；不要重复启动多个后端共享同一数据库。AI 未连接时在官方 Codex 中确认登录，再运行 `doctor:ai`。仅出现页面并不代表真实生成成功，以任务完成和保存结果为准。

2026-10-06：开发界面已对齐最新版原型，保留真实 AI、材料解析和 SQLite。入口改为“当前学习 / 学习历史 / 我的”，项目内提供“学习 / 复习与自测”。具体范围见 [开发对齐说明](./开发对齐说明.md)。

## 使用

1. 双击本目录的 `启动自学.command`，保持终端窗口开启，再在浏览器打开上面的地址。
2. 新建学习项目，先导入至少一份可用材料，再填写主题、目标、基础和每次学习时长。
3. 生成课程目录并确认，进入某课生成真实讲解、案例和练习。
4. 自己作答后提交，AI 结合原文给出反馈；保存笔记、完成课节。
5. 在项目内“复习与自测”写习题或进入研讨室。首次学会安排次日复习，每轮自测完成后安排 3 天后复习。

后台通过官方 Codex app-server 使用本机已经登录的 ChatGPT 账户。无需另填 API Key；仍然需要联网、可用的账户额度和官方 Codex 安装。不会读取或复制登录令牌。当前机器的系统代理会传给应用启动的 AI 子进程，不修改系统代理配置。AI 功能在个人本机环境验证，不是面向公众的账户授权发行方案。

## 当前支持

- YouTube 公开视频已有字幕（含自动字幕）；保留全文和时间戳。受平台限制或无字幕时明确失败，不用视频简介冒充材料。
- PDF 文字层、DOCX、TXT、Markdown、SRT/VTT 和粘贴文字；文件最大 30 MB。
- 分段整理完整材料，课程规划，逐课生成讲解、案例、问题和参考评价要点。
- 原文引用必须匹配才保存；学生接口不返回参考答案和评价要点。
- 真实反馈、原始作答记录、提示使用标记、笔记、完成状态和间隔复习。
- 任务状态、取消与失败重试；课程整理复用已经完成的材料摘要。
- SQLite 持久保存；重启后可重新打开，生成中断会提示重试。

## 明确边界

- 网页和其他视频平台链接、无字幕音频转写、扫描文档 OCR 暂不支持；可改为导入正文。
- 已确认课程可以继续添加材料，但不会自动改写已确认目录或既有课节。
- 复习使用原课练习；变式题与云同步后续实现；研讨室支持两种多轮模式，来源移除保留已有课程引用。
- 自动字幕可能出现人名/术语错误；引用可回到原文时间点核对。嘉宾观点或预测不等于事实认证。
- 完成课节不代表已经掌握。第一版复习按间隔安排，尚未按作答表现动态调整。
- 单机、单用户，仅监听回环地址；不要将端口直接暴露到公网。

## 数据与维护

`data/study.sqlite` 保存项目、来源正文、课程、练习和记录；`data/uploads` 保存上传原件；`data/*.transcript.json` 保存字幕。完整备份时先停止应用，再复制整个 `data` 目录。答题输入草稿额外保存在浏览器本机。

开发命令：

```sh
npm run build --prefix apps/self-study
npm start --prefix apps/self-study
node --test apps/self-study/tests/*.test.mjs
```

依赖安装：在此目录 `npm ci`；字幕依赖使用 `.venv`，运行 `python3 -m venv .venv` 后执行 `.venv/bin/pip install youtube-transcript-api==1.2.4`。构建复用工作区 Vite。模型输出经 JSON Schema 和运行时校验；材料作为不可信数据处理，不授权 AI 执行工具。

官方参考：[Codex app-server](https://developers.openai.com/codex/app-server)。

当前验收范围：仅电脑端、第一课学习闭环。第一版不支持移动端操作。后续课节不预生成。

## 模型设置（2026-10-20）

从“我的 → 模型设置”进入供应商和语言模型。内置 Codex 使用本机已有登录；要固定版本，新增语言模型、选择 Codex、获取可用模型、保存并设为默认。默认项用于后续书籍生成和问答，已有学习内容保留。

其他供应商先填写服务地址与 API Key，选择 Chat Completions、Responses 或 Anthropic Messages 协议，保存后获取模型列表，再保存模型并测试真实生成。兼容服务的地址应包含其要求的版本路径（如 `/v1`）；上下文容量按供应商资料手填。模型能力中的结构化输出会影响请求参数，其他能力仅记录声明，当前学习入口不执行工具。

配置位于实际数据目录的 `model-settings.json`（开发环境通常为 `data-dev`）。密钥和请求头保存在本机文件中，权限为 0600，未加密，不回传浏览器。留空保留已保存凭据，明确勾选清除才删除。备份数据目录时也会包含这些凭据。旧前端草稿可显式导入，密钥需重填。运行任务期间不能修改配置。

验证：全套 28 项测试通过；三种 HTTP 协议已通过本机模拟端点验证；Codex 已完成真实连通测试和独立书籍方案生成。其他供应商需要配置真实凭据后测试。可运行 `node scripts/model-settings-smoke.mjs` 在临时目录执行真实 Codex 书籍方案验收，会消耗少量额度。
